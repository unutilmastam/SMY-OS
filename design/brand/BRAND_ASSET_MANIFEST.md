# SMY-OS brand asset manifest

Every committed logo file, what it is for and where it is used. Generated by
`tools/design/brand_logo.py` (edit the generator, never the SVG). CI checks
that this list and `design/brand/logos/` match exactly
(`tools/design/validate_brand.py`) and that every file passes the SVG rules
(`tools/design/validate_svg.py`). PNG exports are build outputs
(`make brand` → `build/brand/png/`), not committed.
