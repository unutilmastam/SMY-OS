# SMY-OS design asset library

All original visual assets of SMY-OS live here (`docs/DESIGN_PROMPT.md` §11,
`docs/BRAND_PROMPT.md` §13). Generated exports (PNG, preview sheets) are
**not** committed; they are produced by `make brand` into
`build/brand/` and uploaded by CI.

| Path | What | Author | Licence | Source | Status |
|---|---|---|---|---|---|
| `brand/concepts/concept-a-*.svg` | Logo concept A "Module" (symbol, dark/light/mono lockups) | SMY-OS project (generated by `tools/design/brand_concepts.py`) | Apache-2.0 (project licence) | the generator script | concept — **chosen** (ADR 0011) |
| `brand/concepts/concept-b-*.svg` | Logo concept B "Signal" | same | same | same | concept — not chosen (record) |
| `brand/concepts/concept-c-*.svg` | Logo concept C "Prism" | same | same | same | concept — not chosen (record) |
| `brand/logos/smy-*.svg` | Logo family from concept A (22 files, see `brand/BRAND_ASSET_MANIFEST.md`) | SMY-OS project (generated by `tools/design/brand_logo.py`) | Apache-2.0 (project licence) | the generator script | implemented, awaiting owner approval |
| `brand/BRAND_GUIDELINES.md` | Logo construction, clear space, sizes, colours, misuse | SMY-OS project | Apache-2.0 | — | draft until the owner approves the family |
| `tokens/brand-colors.json` | Brand palette (base colour layer) + checked contrast pairs | owner-provided values | Apache-2.0 | `docs/BRAND_PROMPT.md` §4 | implemented |

Rules:

- Every asset is original or has its licence recorded in `LICENSES.md`.
- SVG only, validated by `tools/design/validate_svg.py` (no scripts, raster,
  filters, `<text>` or external references; kebab-case names).
- Logos are generated from documented geometry; edit the generator, not the
  SVG (CI checks they match: `brand_concepts.py --check`, `brand_logo.py --check`;
  the manifest and contrast pairs: `validate_brand.py`).
- Trademark status: no search or registration has been done; nothing here is
  claimed to be legally cleared (`docs/BRAND_PROMPT.md` §15).
