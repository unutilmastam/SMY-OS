# ADR 0011 — Primary logo direction: concept A "Module"

- **Status:** Accepted (owner decision)
- **Date:** 2026-10-21
- **Phase:** 5B

## Context

Phase 5B step 1 produced three original logo concepts with a shared drawn
`SMY-OS` wordmark (`design/brand/concepts/`), evaluated in
`design/brand/concepts/README.md` (A Module 37/40, B Signal 33/40, C Prism
24/40) and shown to the owner as a rendered preview sheet (dark, light,
monochrome, 16/32/64 px). The design quality bar (`CLAUDE.md`) makes brand
choices owner decisions.

## Decision

The owner chose **concept A "Module"**: a rounded-square frame whose
top-right corner is completed by a separate accent square — the core
module. It becomes the master symbol of the SMY-OS logo family, together
with the shared wordmark.

## Consequences

- Step 2 of Phase 5B derives every variant from this symbol: master
  lockups, symbol, wordmark, app icon, light, dark, monochrome, micro mark,
  boot logo, installer logo, developer mark (`docs/BRAND_PROMPT.md` §5).
- Refinement allowed in step 2 without a new decision: proportions, gap
  and corner radii, optical corrections, small-size simplification — as long
  as the idea (frame + separate core in the top-right corner) stays. The
  refined master is shown to the owner again before it is final.
- Known weakness to work on: the core can read as a generic notification
  badge; step 2 tunes its size and spacing so it reads as part of the frame.
- Concepts B and C stay in `design/brand/concepts/` as the record of the
  exploration; they are not used anywhere else.
- No trademark search has been done (`docs/BRAND_PROMPT.md` §15).
